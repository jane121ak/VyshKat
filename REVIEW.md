# Результаты проверки по КПО — домашнее задание № 1

Проверено по `КПО-ДЗ-1-кикшеринг-ВШЭ.pdf`, страницы 2–3. Исправления сделаны поверх присланного проекта, без полной замены архитектуры.

| Что было в исходном коде | Как исправлено | Почему важно |
| --- | --- | --- |
| `ServiceCenter.Inspect` отклонял транспорт при `BeginnerSimplicity < 3` | Техосмотр зависит от `IsServiceable`, список новичков отдельно от `>= 6` | Исправность не равна простоте управления |
| Никакой проверки уникальности инвентарных номеров | `FleetManager` отказывает в дублировании среди вещей и транспорта | Иначе один номер относится к разным объектам |
| Допускались пустые имя/номер, простота вне 1–10, отрицательная энергия | Валидация в конструкторах доменных моделей | Не позволяет накопить некорректные данные |
| `GetAllItems()` возвращал внутренний изменяемый список | Возвращает независимый снимок | Нельзя обойти проверку техосмотра, меняя коллекцию извне |
| Консоль выводила только тип и номер, ожидала `ReadKey` | Выводит наименование и номер, есть режим `--interactive`; `ReadKey` удалён | Выполняется требование к учёту и удобнее автоматический запуск |
| Всего 4 юнит-теста | Добавлены проверки техосмотра, границ, дублей, энергии и инвентаризации | Тесты проверяют поведение, а не только наличие классов |
| Не было README | Добавлены README, инструкции запуска, ответы про SOLID и использование ИИ | Обязательный критерий задания |
| В архиве были `.vs`, `bin`, `obj` | В новом ZIP только исходники, тесты, конфигурация, документы | Чище архив, меньше размер |

## Что важно проверить перед сдачей

1. Выполнить `dotnet restore VyshKat.slnx`, `dotnet build VyshKat.slnx`, `dotnet test VyshKat.slnx` на компьютере с .NET SDK 10.
2. Запустить обычную демонстрацию и `--interactive`; протестировать принятие, отказ и дублирование номеров.
3. Измерить покрытие через `dotnet test VyshKat.slnx --collect:"XPlat Code Coverage"`; ориентир задания — не меньше 60%.
4. Прочитать README, разобраться в `IsServiceable`, DIP и сознательно ограниченном OCP: преподаватель может попросить доработку на защите.

**Ограничение проверки:** в среде подготовки этой версии не установлен .NET SDK и недоступна загрузка из интернета. Поэтому сборку и выполнение тестов **не удалось запустить**; фактический процент покрытия и отсутствие ошибок компиляции не подтверждены. Код дополнительно проверен статически, но это не заменяет `dotnet build/test`.

## Непредусмотренные заданием возможности

Нет базы данных, сохранения парка между запусками, учёта сотрудников, авторизации и настоящей аппаратной диагностики. Это сознательно оставлено за рамками небольшого учебного проекта.
